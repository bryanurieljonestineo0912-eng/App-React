# App Menu

App hecha con React (Vite) para la tarea de Introduccion al Desarrollo de Aplicaciones Moviles.

## Paginas

- Pagina Inicial: datos personales y foto 2x2
- Sumadora: suma dos numeros
- Traductor de Numero a Letras: convierte un numero del 1 al 1000 a letras en espanol (sin usar APIs)
- Tabla de Multiplicar: genera la tabla de un numero hasta el 13
- Experiencia Personal: video de YouTube explicando la experiencia

## Antes de entregar

1. Reemplazar `src/assets/foto.jpg` por tu foto 2x2 real (mismo nombre de archivo).
2. Cambiar el correo en `src/pages/Inicio.jsx`.
3. Subir el video a YouTube (maximo 5 minutos, con tu rostro visible) y reemplazar `VIDEO_ID_AQUI` en `src/pages/Experiencia.jsx` por el ID del video.
4. Subir el proyecto a un repositorio (GitHub).

## Como correr el proyecto

```
npm install
npm run dev
```

Abrir el link que muestra la terminal (normalmente http://localhost:5173).

## Como generar version de produccion

```
npm run build
```

Esto crea la carpeta `dist/` lista para desplegar.
